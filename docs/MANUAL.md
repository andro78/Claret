## 실행

설치가 필요 없다. 자체 포함 폴더를 받아 압축을 풀고 그 안의 **`Claret.exe`**
를 실행한다. .NET과 Windows App SDK 런타임이 폴더에 함께 들어 있어 받는 쪽에서 따로
설치할 것이 없다.

터미널 화면은 WebView2(Microsoft Edge 런타임)로 그린다. Windows 11에는 기본으로 들어 있다.

빌드해서 쓰는 방법은 [README](../README.md#빌드--실행)에 있다.

## 화면 구조

```
┌──────────────────────────────────────────────────────────────┐
│ 🔶  🎨 Options            root@bmc1: ~        Single pane ▾  ─ □ ✕ │  ← 타이틀 바
├───┬──────────────┬───────────────────────────────────────────┤
│ 🌐 │              │  ┌ BMC1 ✕ ┬ COM7 ✕ ┬ + ┐                  │
│ 📁 │  카드         │  │                                       │
│ ⬓ │  (세션/파일/  │  │        터미널                          │  ← 세션 영역
│ 🔧 │   시리얼/도구) │  │                                       │
├───┴──────────────┴───────────────────────────────────────────┤
│ AI ▾   root@bmc1   ● 14 ms   Consolas · 13   Kor             │  ← 상태 바
└──────────────────────────────────────────────────────────────┘
```

**타이틀 바** — 왼쪽부터 앱 아이콘, 모양(팔레트) 버튼, Options 메뉴. 가운데에는 지금 보고
있는 세션이 스스로 밝힌 이름이 놓인다(앱 이름은 표시하지 않는다 — 작업 표시줄에 이미 있다).
오른쪽 끝은 레이아웃 메뉴다.

**왼쪽 레일** — 아이콘 네 개가 카드를 바꾼다.

| 아이콘 | 카드 | 하는 일 |
|---|---|---|
| 지구본 | 세션 | 저장한 접속 목록, 새 접속 |
| 폴더 | 파일 | 원격 디렉터리 트리 (SFTP) |
| DE-9 커넥터 | 시리얼 | COM 포트 목록과 회선 설정 |
| 렌치 | 도구 | 하이라이트 규칙 |

- 같은 아이콘을 다시 누르면 **패널이 접혀** 레일만 남는다. 넓게 쓰고 싶을 때.
- 패널을 **끌어서** 창의 왼쪽/오른쪽에 놓을 수 있다. 오른쪽에 두면 레일도 패널 오른쪽으로
  옮겨간다.
- 패널과 세션 사이 경계를 끌면 너비가 바뀌고, 그 값은 다음 실행에도 유지된다.

## SSH로 접속하기

1. 세션 카드에서 **New connection**을 누른다.
2. 채울 것:
   - **Name** (선택) — 목록에 보일 이름. 비우면 `user@host`로 보인다.
   - **Host / Port / User**
   - **Authentication** — Password 또는 Private key. 비밀번호를 비워 두면 접속할 때 서버가 묻는다.
   - **Private key file** — `id_ed25519` 같은 키 파일. 암호가 걸려 있으면 passphrase도.
   - **Save to profile list** — 목록에 남긴다.
   - **Also save the password / passphrase** — Windows DPAPI로 암호화해 이 사용자 계정에서만
     풀리도록 저장한다. 다른 계정이나 다른 PC로 파일을 옮겨도 풀리지 않는다.
3. 저장한 항목은 **더블클릭**으로 접속한다. 오른쪽 클릭 메뉴에는 Connect / Edit / Delete가 있다.

목록의 각 항목에는 **그 호스트가 지난번에 밝힌 OS 아이콘**이 붙는다 — 리눅스는 펭귄, 우분투는
우분투 마크, macOS는 사과. 한 번도 접속하지 않은 호스트는 지구본이다. 이름에서 짐작하지 않고
접속했을 때 원격이 실제로 답한 것만 기억하므로, 처음 접속한 뒤부터 채워진다.

**호스트 키 확인** — 처음 붙는 호스트의 키는 그대로 저장(pin)한다. 다음에 키가 **달라지면
접속을 거부**하고 알려준다. 정말로 서버를 다시 설치한 것이라면
`%APPDATA%\Claret\known_hosts.json`에서 해당 항목을 지우고 다시 붙는다.

**끊겼을 때** — 링크가 죽으면 5초를 세고 자동으로 다시 붙는다. 화면에 이유와 남은 시간,
시도 횟수가 나오고, 자동 재시도를 멈추는 버튼도 함께 나온다.

## 시리얼 콘솔

레일의 DE-9 커넥터 아이콘을 누른다.

- 목록에는 이름과 함께 장치 설명(`Silicon Labs CP210x USB to UART Bridge` 같은)이 나온다.
  어댑터를 꽂은 뒤에는 **Rescan**을 누른다.
- **Baud rate**, **Data bits, parity, stop**(예: 8N1), **Flow control**을 고르고 **Open COM7**.
  마지막에 쓴 설정은 기억한다.
- 그 포트가 열려 있는 동안 같은 버튼이 **Close COM7**로 바뀐다. 누르면 콘솔을 닫고 포트를 놓는다
  — 탭의 ✕와 같은 일이다. 열기와 닫기는 같은 결정을 양쪽에서 본 것이라 버튼도 하나다. 닫기일
  때는 강조색을 벗는다. 살아 있는 콘솔이 실수로 한 번 눌려 사라지면 안 되기 때문이다.
  목록을 **더블클릭**하는 것은 언제나 열기다 — 라벨이 없는 동작이 콘솔을 닫아서는 안 된다.
- **Pinned** — 자주 쓰는 보드는 이름을 붙여 위쪽 목록에 고정한다. 오른쪽 클릭으로 Open /
  Rename / Unpin.
- 이미 열려 있는 포트를 다시 열려고 하면 그 세션으로 **가겠느냐고 묻는다**. 포트는 한 번에
  하나만 열 수 있어서, 조용히 실패하는 대신 열려 있는 쪽을 알려주는 편이 낫다.
- **Break 신호** — 탭을 오른쪽 클릭하면 **Send break**가 있다(시리얼 탭에만 나온다). 보드에서
  이것은 부트로더로 떨어지는 신호라 단축키에는 넣지 않았다. 메뉴로만 보낼 수 있다.
- 포트를 열 때 DTR을 올리고, 흐름 제어가 RTS를 쓰지 않는 설정이면 RTS도 올린다.

시리얼 세션은 SSH 세션과 똑같이 다룰 수 있다 — 분할, 로그, 하이라이트 모두 같다.

## 세션 다루기

- **새 세션** — 탭 줄의 `+` 또는 `Ctrl+Shift+T`.
- **분할** — 탭을 오른쪽 클릭 → **Split right** / **Split down** (`Alt+Shift++`, `Alt+Shift+-`).
  각 창(pane)은 자기 탭 줄을 갖는다. 창 하나에 탭이 여러 개 있을 수 있다.
- **Duplicate** — 같은 호스트에 두 번째 셸을 연다. 비밀번호를 다시 묻지 않는다.
- **레이아웃 메뉴**(타이틀 바 오른쪽 끝) — 세 가지.
  - `Single pane (merge all)` — 모든 세션을 한 창의 탭으로 모은다.
  - `Spread all sessions left to right`
  - `Spread all sessions top to bottom`
- **세션 순환** — `Ctrl+Tab` / `Ctrl+Shift+Tab`.
- **닫기** — 탭의 ✕ 또는 `Ctrl+Shift+W`.
- 창 사이 경계를 끌어 비율을 바꿀 수 있다.

접속이 진행되는 동안 탭 아이콘은 회전 표시이고, 붙고 나면 원격이 무엇인지에 따라 아이콘이
바뀐다 — 리눅스는 펭귄, 우분투는 우분투 마크, 시리얼은 DE-9 커넥터. `/etc/os-release`를 읽어
판단하고, 못 읽으면 SSH 배너로 짐작한다.

## 복사와 붙여넣기

기본은 **선택하면 곧바로 클립보드에 들어간다**(Options → `Copy on selection`).

| 동작 | 키 |
|---|---|
| 붙여넣기 | 가운데 클릭, `Ctrl+V`, `Ctrl+Shift+V` |
| 복사 | 마우스로 선택(기본), `Ctrl+Shift+C` |
| 인터럽트(SIGINT) | `Ctrl+C` |

`Ctrl+C`는 선택 즉시 복사가 켜져 있는 동안 **항상 SIGINT**다. 화면에 선택이 남아 있다고
인터럽트를 삼키는 터미널은 터미널이 아니기 때문이다. 선택 즉시 복사를 끄면 `Ctrl+C`는
선택이 있을 때만 복사하고, 선택이 없으면 다시 SIGINT가 된다.

여러 줄을 붙여넣으면 bracketed paste로 들어가므로, 받는 쪽 CLI가 첫 줄에서 실행해 버리지
않는다.

## 한글 입출력

터미널에서 한글이 칸에 맞으려면 한글 글자 폭이 영문 글자 폭의 **정확히 두 배**여야 한다.
영문 고정폭 글꼴에 한글만 다른 글꼴로 대체되면 이 비율이 깨져 줄이 어긋난다.

그래서 글꼴을 **Automatic**으로 두면, 이 PC에 있는 글꼴을 실제로 재서 한글 폭이 두 배로
맞는 것을 고른다. 찾는 순서는 D2Coding → NanumGothicCoding → GulimChe → DotumChe이고,
하나도 없으면 Cascadia Mono에 Malgun Gothic으로 대체한다.

상태 바 오른쪽의 **`Kor` / `Eng`** 표시는 지금 입력이 한글인지 영문인지 알려준다. 한/영 키로
바꾸면 표시도 바뀐다. 조합 중인 글자는 IME가 끝낼 때까지 앱이 건드리지 않는다.

## 모양과 글꼴

**타이틀 바의 팔레트 버튼** — 색 구성표와 글꼴을 고른다. 프리셋은 Campbell(기본), Pastel,
One Half Dark, Nord, Dracula, Gruvbox Dark, Tokyo Night, Solarized Dark, Solarized Light.
배경과 글자색은 직접 손볼 수도 있다. 미리보기에 프롬프트 한 줄, 로그 색, 한글, 자 눈금이
같이 나오므로 한글 폭이 맞는지 여기서 바로 보인다.

**상태 바의 글꼴 표시**(`Consolas · 13` 같은) — 누르면 글꼴과 크기 대화상자가 열린다.

터미널에서 `Ctrl++` / `Ctrl+-`로 크기를 바꾸고 `Ctrl+0`으로 기본(14)으로 되돌린다.

## 하이라이트 규칙

레일의 렌치. 출력에 나타나는 글자에 색을 입힌다.

- **Add rule**에서 찾을 글자를 넣는다. 정규식이 아니라 **그대로의 글자**다.
- **Style** — `Block`은 글자 뒤를 칠하고, `Text only`는 글자색만 바꾼다.
- **Color** — `Auto`로 두면 다른 규칙이 쓰지 않는 색을 앱이 골라 준다. 규칙을 여러 개 만들 때
  색을 고민하지 않아도 된다.
- 체크박스로 규칙을 켜고 끈다. 규칙은 모든 세션에 함께 적용된다.

`error`, `warn`, `FAIL` 같은 것을 넣어 두면 긴 부팅 로그에서 눈이 먼저 간다.

## 콘솔을 파일로 남기기

탭을 오른쪽 클릭 → **Log to file…** 로 위치를 고른다. 기록 중이면 같은 자리가
`Stop logging (파일명)`으로 바뀐다. 상태 바에도 기록 중임과 파일 이름이 나온다.

- 파일에는 **읽을 수 있는 글자만** 들어간다. 색과 커서 이동, 창 제목을 바꾸는 이스케이프는
  걷어낸다. 몇 주 뒤에 사람이 읽을 파일이기 때문이다.
- 시작한 시점부터 기록한다. 이미 화면에 있던 것은 파일에 없다.
- 같은 파일을 다시 열면 덧붙인다. 열 때와 닫을 때
  `==== root@bmc1 · 2026-08-22 14:31:02 ====` 같은 줄을 넣는다.

## 원격 파일 (SFTP)

레일의 폴더 아이콘. 접속한 세션의 원격 디렉터리를 트리로 보여준다.

Options → **SFTP** 메뉴:

- **Show files in the tree** — 디렉터리만 볼지, 파일까지 볼지.
- **Upload files…** / **Download selected file…**
- **Upload folder…** / **Download selected folder, with everything in it…** — 아래 참조.
- **Download folder…** — 받는 위치를 정해 두거나, **Ask where to save each file**로 매번 묻게 한다.
- **Refresh folder tree**

트리에서 디렉터리를 오른쪽 클릭하면 같은 것들이 그 자리에 있다 — **Download this folder…**,
**Upload files here…**, **Upload a folder here…**, 그리고 그 경로로 `cd` 하는 명령을 터미널에
보내는 **Go to this folder**.

파일은 트리에 **끌어다 놓아** 올릴 수도 있다. 폴더도 놓을 수 있다. 어디에 놓든 올라가는 위치는
**트리에서 선택한 디렉터리**다 — 놓는 동작은 거칠고, 선택은 일부러 한 것이기 때문이다. 끌고
있는 동안 그 경로가 표시된다.

### 폴더 단위 전송

폴더를 통째로, 그 안의 트리 모양 그대로 옮긴다. 양쪽 방향 모두 같은 규칙이다.

- **먼저 센 다음 시작한다.** 파일 개수와 전체 크기를 먼저 읽고, 그 값으로 진행률을 보여준다.
  얼마나 남았는지 말할 수 없는 진행 바는 스피너와 다를 게 없다.
- **링크는 따라가지 않는다.** 심볼릭 링크와 정션은 건너뛰고 그 개수를 끝에 알려준다. 자기
  부모를 가리키는 링크 하나로 영원히 도는 복사가 되기 때문이다.
- **한 번만 묻는다.** 받는 쪽에 같은 이름의 폴더가 이미 있으면 시작 전에 한 번 묻는다 —
  **Replace files**(같은 이름 파일 덮어쓰기) / **Keep existing**(그대로 두고 나머지만) /
  Cancel. 폴더 안의 다른 것은 어느 쪽이든 손대지 않는다. 파일 300개를 하나씩 묻는 것은 동의가
  아니라 피로다.
- **한 파일이 실패해도 나머지는 계속한다.** 읽을 수 없는 파일은 세어서 끝에 알려준다.
- **너무 크면 시작하지 않는다.** 항목 20,000개를 넘는 폴더는 거부하고 그렇다고 말한다. 잘못
  누른 한 번이 한 시간짜리 복사가 되지 않도록.
- 진행 중에는 언제든 취소할 수 있고, 그때까지 몇 개가 갔는지 알려준다.

끝나면 `4 files, 2 kept, 1 link skipped`처럼 실제로 일어난 것만 적어 보여준다.

## AI CLI

상태 바 왼쪽의 **AI ▾**. 이 메뉴는 **접속한 원격 쪽에** AI 코딩 CLI를 설치한다(내 PC가 아니다).
메뉴 항목 오른쪽에 설치될 곳이 함께 적혀 있다.

| 항목 | 설치되는 것 |
|---|---|
| Install Claude Code | Anthropic 공식 설치 스크립트 |
| Install Gemini CLI | npm `@google/gemini-cli` |
| Install Codex CLI | npm `@openai/codex` |

- 누르면 어떤 명령이 어디서 실행되는지 확인을 받고 나서 터미널에 입력한다.
- **Copy … command** — 명령만 클립보드로 받아 직접 실행할 수 있다.
- npm이 필요한 것은 npm이 없으면 설치를 시도하지 않고 Node.js가 필요하다고 알린다.

### 프롬프트 자동 답변

AI CLI가 `1. Yes, proceed / 2. No` 같은 확인을 물을 때 자동으로 승인하게 할 수 있다.

- **Answer "Yes, proceed" automatically — this session** — **세션 단위**다. 창을 열 때마다
  꺼진 상태에서 시작하고, 지금 하는 작업에 대해서만 켠다.
- **Never auto-answer on `호스트`** — 그 호스트에서는 아예 못 켜게 한다. 이 설정은 기억되고,
  이미 켜져 있던 것도 함께 내린다.
- 자동으로 답했을 때는 상태 바가 무엇을 택했는지 보여준다.

승인 프롬프트는 원래 사람에게 묻기 위한 것이다. 켜기 전에 그 세션에서 무엇을 하고 있는지
생각할 것.

## 상태 바 읽기

왼쪽부터:

- **AI ▾** — 위 항목.
- **세션** — 지금 보고 있는 세션(`root@bmc1`, `COM7 · 115200 8N1`)과 원격 플랫폼.
- **기록 표시** — 파일로 남기는 중일 때 파일 이름.
- **auto-yes** — 자동 답변이 켜져 있을 때, 그리고 마지막으로 자동 선택한 항목.
- **신호등 + 왕복 시간** — SSH 세션의 응답 시간.
  | 색 | 뜻 |
  |---|---|
  | 초록 | 60 ms 이하 |
  | 노랑 | 200 ms 이하 |
  | 빨강 | 그보다 느리거나 응답 없음 |

  시리얼 세션은 왕복을 잴 상대가 없다 — 케이블이 곧 네트워크다. 그래서 초록 불만 켜고 숫자는
  비운다.
- **글꼴 · 크기** — 누르면 글꼴 대화상자.
- **`Kor` / `Eng`** — 입력기 상태.

## 키보드 단축키

터미널이 포커스를 갖고 있어도 같은 키가 동작한다.

| 키 | 하는 일 |
|---|---|
| `Ctrl+Shift+T` | 새 세션 메뉴 |
| `Ctrl+Shift+W` | 지금 세션 닫기 |
| `Ctrl+Shift+B` | 왼쪽 패널 접기/펴기 |
| `Alt+Shift++` | 오른쪽으로 분할 |
| `Alt+Shift+-` | 아래로 분할 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 세션 |
| `Ctrl+Shift+C` | 복사 |
| `Ctrl+V`, `Ctrl+Shift+V`, 가운데 클릭 | 붙여넣기 |
| `Ctrl+C` | 인터럽트(SIGINT) |
| `Ctrl++` / `Ctrl+-` | 글자 크기 |
| `Ctrl+0` | 글자 크기 기본값 |

모두 `%APPDATA%\Claret\` 아래에 있다. 폴더째 복사하면 설정이 따라간다 — 단
**저장된 비밀번호는 따라가지 않는다**(DPAPI로 이 계정에 묶여 있다).

| `layout.json` | 패널 위치와 너비, 선택 즉시 복사, 마지막 시리얼 설정, 자동 답변 차단 호스트 |

| `serial.json` | 고정한 시리얼 프로필 |

## 잘 안 될 때

**접속이 거부되고 호스트 키가 다르다고 나온다** — 서버 키가 실제로 바뀌었다. 재설치한
서버라면 `known_hosts.json`에서 그 항목을 지우고 다시 붙는다. 그런 일이 없었다면 붙지 말고
확인부터 할 일이다.

**COM 포트가 목록에 없다** — 어댑터를 꽂고 **Rescan**. 장치 관리자에서 드라이버가 올라왔는지
확인한다. 블루투스 가상 포트도 함께 나오므로 장치 설명을 보고 고른다.

**포트를 열 수 없다** — 다른 프로그램(다른 터미널, 이 앱의 다른 탭)이 쥐고 있다. 이 앱의
다른 탭이면 열려 있는 쪽으로 가겠느냐고 묻는다.

**한글이 칸에서 어긋난다** — 글꼴을 **Automatic**으로 되돌린다. 특정 글꼴을 골랐고 그 글꼴의
한글 폭이 영문의 두 배가 아니면 어긋난다. 대화상자 미리보기의 한글 줄과 눈금 줄을 비교하면
바로 보인다.

**출력 아래쪽이 잘려 보인다** — 창 크기를 한 번 바꾸면 다시 맞춰진다. 계속 그러면 알려줄 것.

**앱이 ".NET을 설치하라"는 대화상자를 띄운다** — 폴더가 온전하지 않다. 자체 포함 폴더 전체를
다시 받아 압축을 풀 것. exe 하나만 옮겨서는 실행되지 않는다.
